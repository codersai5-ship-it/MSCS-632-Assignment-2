# MSCS-632 Assignment 2

## Syntax, Semantics, and Memory Management

This repository contains the programs used for Assignment 2 in **MSCS-632: Advanced Programming Languages**.

### Part 1: Syntax and Semantics

The `syntax-errors` folder contains correct and intentionally incorrect versions of Python, JavaScript, and C++ programs used to compare syntax-error handling.

The `semantics` folder contains type-system examples for Python, JavaScript, and C++.

### Part 2: Memory Management

The `memory-management` folder contains examples demonstrating:

- Rust ownership and borrowing
- Java garbage collection
- C++ manual memory management

Memory usage and execution time were also observed using an online execution environment for comparison in the submitted report.
